Index Pages
- allow parent pages to define a set of child pages to show in the nav
- child page nav will be embedded under its nav item from parent list
- clicking top level items in nav will open that child page
- store these in schema under '' prop like so ['heading', null, 'child-1', 'child-2', etc...]


composite pages
- have chain slashes to backtrack to include other pages
- display only the sections from the first page that are also included in the other pages
- content for each section will be displayed in a columns, with the heading of each section from the first page centered above each row
